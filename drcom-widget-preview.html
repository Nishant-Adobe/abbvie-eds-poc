What is the drcom-widget?
The drcom-widget block lazy-loads the Doctor.com (Dr.com) directory widget — a third-party <directory-widget> custom element that renders a physician/specialist finder form. It loads the external script from https://widget.doctor.com/directory/app.js only when the block enters the viewport (IntersectionObserver). Each brand configures it with a unique partner-id provided by Doctor.com.

Authoring fields: partner-id (required), heading (optional), api-env (prod/test)
